# Security policy

## Scope

The current release includes text prompts, example documents and a local Python score calculator. It does not expose a web server, run an AI API client, or connect to accounts. Do not add authentication tokens to review JSON or public issues.

## Reporting

If you believe there is a security issue, avoid posting exploit details or secrets publicly. Open a GitHub private vulnerability report via the repository's **Security** tab if available. Otherwise, open an issue containing only non-sensitive details and request a private contact method.

## Supported releases

Only the latest tagged `0.1.x` release is actively targeted for fixes during the foundation phase. No warranty or security guarantee is provided; see `LICENSE`.
