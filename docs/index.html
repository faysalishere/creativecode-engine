FROM BRIEF TO DECISION 03

A better process.
Not more effects.

The toolkit is intentionally small: clear prompts and a dependency-free Python CLI. Its review outputs are evidence-guided, not automatic aesthetic judgments.

01

Frame the problem

Define your users, the job to be done, constraints and assets before designing anything.

02

Explore alternatives

Generate three curated structural blueprints and compare their navigation and content models.

03

Challenge the work

Record originality heuristics, review questions, uncertainty and evidence gaps.

04

Choose, then code

Approve a direction, implement separately, and test real interactions. No automatic deployment.

TERMINAL / PYTHON 3.10+
# clone and enter the project
git clone https://github.com/faysalishere/creativecode-engine.git
cd creativecode-engine

# generate three design blueprints
python3 -m creativecode concepts \
  --brief examples/portfolio_brief.json \
  --out /tmp/creativecode-concepts.json

No AI model, paid API, or browser-based coding agent is included. This example uses a rule-based concept engine.

HONEST BY DESIGN 05

What it does.
What it doesn't.

Included today

Design framework, prompts, deterministic concept blueprints, structural originality checks, critic review packets, and an interactive study.

Not included

A hosted AI model, autonomous software builder, automated visual originality verdict, or automatic deploy-to-production agent.

Why it matters

Professional design requires context, honest evidence and human judgment. A passing checklist is not a guarantee of quality.
